# Support

Disha Voice is a prototype in progress and is not release-ready. Features, builds, and documentation may be incomplete or unverified.

## Usage and project questions

For usage questions, setup help, documentation corrections, or general project discussion, use the repository's GitHub Discussions or open a public issue if those features are available. Search existing issues first. Keep reports focused and include relevant environment details, exact steps to reproduce, and logs with secrets and personal information removed.

Do not include private photographs, video, audio, recordings, screenshots, location data, credentials, or other personal or confidential information in a public report. Use synthetic or properly licensed public examples instead.

## Bugs and feature requests

Use the repository's **Bug report** or **Feature request** issue form, if available. State what you expected and what happened. Feature proposals should respect the project's scope: visual information and image-relative object descriptions only, not medical advice or mobility, navigation, collision-avoidance, or path-clearance guidance.

## Security concerns

Do not report vulnerabilities in public issues, discussions, or pull requests. Follow the private reporting instructions in [SECURITY.md](SECURITY.md). GitHub private vulnerability reporting may be used only if it is enabled and offered for the repository; no alternate security email is designated here.

## Support expectations

There is no guaranteed response time, support service-level agreement, or promise that a request will be implemented. This project is not an emergency, medical, or safety-support service. Do not rely on it for travel, hazard avoidance, diagnosis, treatment, or other safety-critical decisions.
