# Security Policy

## Reporting a vulnerability

Report security vulnerabilities affecting Disha Voice, this repository, or its maintained dependencies **only through GitHub's private vulnerability reporting**:

1. Open the repository on GitHub and go to **Security**.
2. Choose **Advisories** / **Report a vulnerability** (the exact label can vary) and submit the report privately through GitHub.

**This channel is available.** The repository is public (`github.com/shubhsaxena2020/disha-voice`)
and private vulnerability reporting was enabled for it on 2026-10-21. The **Security** tab
therefore shows a **Report a vulnerability** form, and anything you submit there is visible
only to the maintainers. GitHub's own documentation describes the feature and its
visibility. [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/enabling-private-vulnerability-reporting-for-a-repository).

**If the private report option is nevertheless unavailable** — for example if the
repository is transferred, the feature is later disabled, or you are looking at a mirror —
do not post vulnerability details in a public issue, discussion, pull request, commit, or
other public channel. No alternative security contact is designated here. If you already
have an established private GitHub channel with a repository maintainer, you may use it
only to ask that private vulnerability reporting be enabled, not to send vulnerability
details. Otherwise, wait until a private reporting route is available. Do not invent or
infer an email address or other contact.

Please include the affected component or revision, impact, steps to reproduce, and a suggested mitigation if known. Keep testing limited to systems and data you own or are authorized to test. Do not access, alter, or disclose other people's data, and do not attach private media or secrets. Avoid public disclosure while a report is being assessed. The project makes no response-time or remediation-time commitment; any follow-up and disclosure coordination will depend on maintainer capacity and the circumstances.

## Scope and safety

Reports may concern vulnerabilities in project code, build or release processes, dependencies, or project-operated services. Disha Voice is a prototype visual-information assistant, not a medical product or a mobility, navigation, collision-avoidance, or path-clearance aid. Do not use it to make safety-critical decisions or test it in a way that could put anyone at risk.
